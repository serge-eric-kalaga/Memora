# Memora

Lire d'abord `agents/README.md` et `agents/memory/state.md`, puis uniquement les fichiers utiles au jalon courant. Préserver les instructions spécifiques de `frontend/AGENTS.md`.

Les projets de référence sont en lecture seule. Aucun push, déploiement public ou envoi réel d'email. Tests uniquement sur données synthétiques. Ne jamais enregistrer de secrets dans les notes ou logs.

Exception explicitement autorisée le25/10 : comparaison sur une copie locale d'un unique enregistrement de test désigné par l'utilisateur, sans modifier l'original ni envoyer l'audio à un tiers. Détails et résultats privés restent dans `.memora/accuracy-private/`, jamais dans les notes ou logs. La référence fournie étant reformulée, aucun score de précision personnel n'est valable ; les autres tests restent synthétiques.
